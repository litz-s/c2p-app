# C2P - Copy/Paste Tables (JavaFX)

小さなお試し開発アプリ。複数の「コピペテーブル」を管理し、各テーブル内で大量のテキストスニペットをスクロールしながら使えるヨウ。
- メイン画面右上の「＋」で新規テーブルを作成
- 「編集」で既存テーブルの名前変更
- テーブル画面では：
  - 行（テキストエリア）は**シングルクリックでコピー**、**ダブルクリックで編集**、**フォーカスアウトで保存**
  - 編集中は Enter で改行、Tab でインデント

## 自分でビルドする人向け必要環境 (二次創作？)
- OpenJDK 21（推奨）
- Gradle 8系（VSCodeを使う場合はJava Extension Packが入っていればビルド/実行しやすい）

## 実行方法（Windows）
```bash
# 1) プロジェクト直下で（gradleラッパーが未生成の場合）
gradle wrapper

# 2) 実行
.\gradlew run      # Windows PowerShell
```

VSCode なら、拡張機能「Java Extension Pack」を入れた上で、`App.java` を開いて「Run」ボタンから起動できます。

## 保存先
ユーザーホーム直下の `~/.c2p/c2p.json` にテーブルデータを保存しています。

## 注意
- 大量の行も `ListView` の仮想化で軽快に動作する。ケド、極端に大きいテキストを大量に詰めるとパフォーマンスが落ちる場合がアルヨ。
